# World Cup 2026 Bracket Guessing Game

Welcome to the World Cup 2026 Bracket Guessing Game! This exciting project allows football fans across the globe to engage with the tournament by predicting match outcomes and participating in friendly competition.

## Project Description

As the anticipation builds for World Cup 2026, fans can immerse themselves in the thrill of the game by making predictions on:
- **Game Winners**: Vote on who will come out on top in each match.
- **Exact Scores**: Guess the final scores of the matches to earn points for accuracy.
- **Leading Scorers**: Predict which players will score the most goals throughout the tournament.

### Features
- **User Registration**: Create an account to track your scores and predictions.
- **Leaderboard**: Compete against friends and users worldwide for the top spot based on your prediction accuracy.
- **Real-Time Updates**: Stay updated with live scores and changes throughout the tournament.
- **Discussion Forum**: Engage with other users to discuss predictions, strategies, and match insights.

### Getting Started
1. Clone the repository: `git clone https://github.com/reuvenimeiron-ui/modialBracket`
2. Install the necessary dependencies: `npm install` (or your preferred package manager)
3. Start the application: `npm start`
